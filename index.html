Tentang Aplikasi Ini

RidosaurusApp adalah Weather App yang dibuat untuk memenuhi Tugas Rutin 5 mata kuliah Pemrograman Web. Aplikasi ini mengambil data cuaca secara langsung dari OpenWeatherMap API menggunakan fetch dan async/await, lalu menampilkan nama kota, suhu, deskripsi cuaca, ikon, dan kelembaban.

Aplikasi ini juga menampilkan waktu lokal kota yang dicari, peta lokasi kota tersebut, serta riwayat pencarian yang tersimpan di LocalStorage dan pilihan satuan suhu °C / °F. Aplikasi dilengkapi penanganan error untuk kota yang tidak ditemukan maupun gangguan jaringan, beserta indikator loading saat data sedang diambil.
